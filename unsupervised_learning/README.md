# Dimensionality Reduction – PCA

## Files
- `0-pca.py`: PCA with target variance (default 95%)
- `1-pca.py`: PCA with fixed number of components
- `mnist2500_X.txt`: Dataset (2,500 samples, 784 features)
- `mnist2500_labels.txt`: Labels (digits 0–9)

## How to Run

```bash
chmod +x 0-main.py 1-main.py
./0-main.py
./1-main.py
