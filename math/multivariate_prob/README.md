Multivariate Probability Project

This project implements key concepts from multivariate probability and statistics in Python using only NumPy. It is part of the Holberton School Machine Learning curriculum and focuses on building tools for understanding and working with multivariate Gaussian distributions.

📚 Learning Objectives

By the end of this project, you should be able to explain:

👨‍🔬 Who Carl Friedrich Gauss was and why the Gaussian distribution is named after him.

🔗 What a joint/multivariate distribution is.

📈 What covariance measures.

📉 What the correlation coefficient represents.

🧱 What a covariance matrix is and how to compute it.

🔮 What a multivariate Gaussian distribution is and how to calculate its PDF.

🛠️ Requirements
