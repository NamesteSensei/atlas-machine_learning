# Keras Neural Network Project



---

## 🧩 Task 0: Sequential

### Goal
Write a function `build_model(nx, layers, activations, lambtha, keep_prob)`  
that builds a neural network with **Keras**:

- `nx`: number of input features  
- `layers`: list of node counts for each layer  
- `activations`: list of activation functions for each layer  
- `lambtha`: L2 regularization parameter  
- `keep_prob`: probability that a node is kept (for Dropout)

**Constraints:**
- Must use `import tensorflow.keras as K`  
- Must not use `Input` class  
- Must follow **pycodestyle** (PEP8)  
- All functions, modules, and classes must have docstrings  
- All files must be executable with `#!/usr/bin/env python3`
