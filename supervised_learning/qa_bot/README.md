# QA Bot

This project implements a Question Answering chatbot using BERT.

## Features
- Single-document QA
- Interactive chatbot loop
- Semantic search across documents
- Multi-reference QA system

## Requirements
- Python 3.9
- TensorFlow 2.15
- tensorflow-hub 0.15.0
- transformers 4.44.2
