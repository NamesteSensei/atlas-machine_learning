# NLP Evaluation Metrics

This project demonstrates how to build and evaluate a simple text
classifier using essential NLP evaluation metrics.

We use a Naive Bayes classifier on a dummy dataset to analyze
performance using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
