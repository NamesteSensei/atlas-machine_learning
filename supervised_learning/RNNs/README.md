# Recurrent Neural Networks (RNNs)

This project implements basic Recurrent Neural Network components in Python using NumPy.

## Task 0: RNNCell
Implements a simple RNN cell capable of performing one forward propagation step:
- Initializes weights (`Wh`, `Wy`) and biases (`bh`, `by`)
- Computes next hidden state using tanh
- Computes output using softmax

### Files
- `0-rnn_cell.py` — Defines the `RNNCell` class
- `0-main.py` — Test script
