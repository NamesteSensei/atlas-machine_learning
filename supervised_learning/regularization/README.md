Regularization in Machine Learning

This project explores **regularization techniques** in machine learning, implemented
using **NumPy** and **TensorFlow/Keras**.

Regularization helps prevent **overfitting** by penalizing complex models and
encouraging simpler, more generalizable solutions.

---

Learning Objectives

By the end of this project, you should be able to explain:

- What is **regularization**? Why is it important?
- What are **L1** and **L2** regularization?  
  - Key differences
- What is **Dropout** and why does it help?
- What is **Early Stopping**?
- What is **Data Augmentation**?
- How to implement regularization methods in **NumPy** and **TensorFlow**
