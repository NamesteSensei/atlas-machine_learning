# 🎯 Policy Gradient Reinforcement Learning (REINFORCE)

Welcome to a hands-on implementation of the REINFORCE algorithm using pure NumPy and OpenAI's Gymnasium.

This project is an educational dive into **Policy Gradient Methods** — specifically the Monte Carlo approach known as **REINFORCE**.

## 🤖 Objective

The goal is to:
- Understand what a policy is in Reinforcement Learning.
- Learn how to compute policy gradients.
- Implement the REINFORCE algorithm step-by-step.

## 📚 Requirements

- Python 3.9
- numpy==1.25.2
- gymnasium==0.29.1
- pycodestyle==2.11.1
